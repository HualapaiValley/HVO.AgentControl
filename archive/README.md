# V1 Archive

`v1/` preserves the tracked root tree from commit
`e8fa53f` (Recover GitHub renewal and keep fleet monitoring observable, #205).
Files retain their contents and relative layout. Git history remains intact.

This is reference material, not part of the V2 build. In particular, archived
workflows, agent instructions, provisioning scripts, and compose files are not
active V2 configuration. Do not run them against existing infrastructure.

Open V1 GitHub issues and pull requests are labeled `v1-Archive` and closed
without merging. Their discussions and branches remain available on GitHub.
Unmerged PR changes are not included in this main-branch snapshot.
